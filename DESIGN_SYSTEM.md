# Design System

## Direction

Industrial-design exhibition + calm architecture + robotics laboratory.

The site should feel bright, tactile and engineered rather than neon, cyberpunk or "AI generated".

## Palette

- Paper: `#F4F0E8`
- Warm white: `#FFFDF8`
- Limestone / sand: `#D7C7AE`
- Sage: `#9AA596`
- Mist blue: `#A9BBC4`
- Clay: `#B98569`
- Rose accent: `#C7A29A`
- Graphite: `#343536`
- Main ink: `#242624`

## Typography

The project uses a high-quality system sans stack rather than depending on a remote font CDN. Technical labels use a system monospace stack.

## Motion

- large movement belongs to the 3D camera, not every text element
- transitions are slow enough to read as spatial travel
- UI hover motion is small and tactile
- `prefers-reduced-motion` removes non-essential motion

## Project worlds

3D motifs intentionally follow the engineering domain:

- SLAM: ground plane, robot, trajectory, point cloud
- Arm: joints, links, target object, physical material contrast
- PCB: board, traces, components, macro inspection
- JARVIS: bounded network / state visualization, no blue hologram cliché
- Aurelia: warmer and softer network language
- HTTP server: discrete spatial nodes and network paths
