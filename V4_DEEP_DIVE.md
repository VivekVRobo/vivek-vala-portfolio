# Vivek Vala Spatial Portfolio v4 — Deep-Dive Upgrade

## Why v4 exists

v3 had the right structure, honest project evidence, and a real multi-page architecture, but it still had three design ceilings:

1. the homepage camera moved between worlds without enough sense of spatial arrival;
2. case studies were technically strong but repeated the same reading rhythm too often;
3. non-project routes shared too much of one generic architectural scene.

v4 focuses on authored experience rather than simply adding more effects.

## What changed

### Spatial homepage
- Added architectural portal/threshold objects between the major homepage disciplines.
- Added a fixed chapter-aware spatial journey rail on larger screens.
- Added chapter metadata for ROS/SLAM, kinematics, embedded hardware, and intelligent systems.
- Added a three-principle engineering statement between the hero and the 3D journey.
- Added subtle spatial coordinate language to the hero.
- Camera choreography now changes FOV through the journey instead of using one fixed lens.

### Project-specific 3D
- Replaced one generic project orbit with scene-specific camera presets.
- SLAM, arm, gesture arm, PCB, server, line follower, sorter, JARVIS, Aurelia, and RCI now use different camera paths.
- JARVIS now uses an orchestration/module world rather than the generic intelligence sphere.
- Aurelia now uses a softer character/runtime stage composition.
- RCI now includes explicit cognition → safety boundary → robotic-actuation spatial language.
- About, Lab, Experience, Blog, Resume, and Contact now have route-specific quiet 3D compositions.

### Case-study reading experience
- Added sticky section navigation for engineering question, architecture, decisions, evidence, and validation.
- Added an at-a-glance project snapshot for discipline, maturity, evidence volume, and core stack.
- Added a large next-project transition at the end of each case study.
- Real project images can open in an accessible native dialog/lightbox.
- Evidence placeholders now render as abstract engineering diagrams instead of empty boxes while remaining clearly placeholders.

### Owner / CMS workflow
- Projects now support Draft vs Published state.
- New projects default to Draft so unfinished entries cannot leak into the public project index.
- Studio displays case-study completeness percentage.
- Studio exposes a project Preview action.
- Homepage statistics and capabilities are directly editable in Studio.
- v4 migrates v3/v2 local browser content automatically.

### User control + accessibility
- Added a manual 3D On/Off control in navigation.
- Scene preference persists locally.
- Low-power/save-data fallback remains automatic even when 3D is enabled.
- Added View Transitions API enhancement with reduced-motion fallback.
- Existing keyboard navigation, skip link, focus restoration, reduced-motion support, and evidence semantics remain intact.

### Experience/About improvement
- The Experience page now uses projects as proof of current technical practice rather than padding a student timeline with invented work history.
- About now includes explicit engineering operating principles.

## Design direction retained

v4 keeps the requested natural material palette:

- ivory / warm white
- limestone / sand
- muted sage
- mist blue
- warm clay
- soft rose
- graphite

No neon green, electric cyan, purple AI gradients, or gamer-style visual language was introduced.
